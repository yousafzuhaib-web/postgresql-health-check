# PostgreSQL Health Check

A practical PostgreSQL health-check toolkit for reviewing database performance, configuration, replication, storage, vacuum activity, and index usage.

## Checks included

- Database and server overview
- Active and idle sessions
- Long-running queries
- Database and table sizes
- Index usage
- Unused indexes
- Dead tuples and vacuum activity
- Replication status
- PostgreSQL configuration review

## Use cases

This toolkit is useful for:

- Production database assessments
- Performance troubleshooting
- Capacity reviews
- Migration preparation
- High availability validation
- Preventive maintenance

## Requirements

- PostgreSQL 12 or later
- Read access to PostgreSQL system views
- Additional privileges may be required for some statistics

## Disclaimer

Review every query before running it in production. Test first in a non-production environment whenever possible.
